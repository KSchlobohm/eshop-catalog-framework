# Glossary

| Term | Meaning |
|------|---------|
| Catalog API | The standalone Web API 2 sample that manages products and includes Swagger UI. |
| ASP.NET Identity | The local account framework; its EF user store and `UserManager` create users and verify passwords. |
| SKU | Stock keeping unit: a product identifier, such as `MUG-001`. |
| JWT | JSON Web Token: the bearer token issued at login to authorize product operations. |
| LocalDB | The local SQL Server instance used for the sample database. |
